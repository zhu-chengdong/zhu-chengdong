# Chengdong Zhu · 朱铖栋

PhD researcher in Electronic Engineering at the **University of York**, working on **robotic system integration, robot perception, and robot control**.

My current projects cover underwater robotic platforms, visual localization and SLAM, stereo dataset development and evaluation, and vision-guided robotic arm control.

[Website](https://zhuchengdong.com) · [Email](mailto:chengdong.zhu@york.ac.uk) · [ORCID](https://orcid.org/0000-0001-5877-2650)

## Research and projects

- **[Underwater robot platform development](https://github.com/zhu-chengdong/rov-v1-hardwarex)** — Design and integration of the ROV V1 platform, including mechanical design, electrical and sensor integration, ROS integration, and experimental testing.
- **[York-Tank](https://github.com/zhu-chengdong/York-Tank)** — Underwater data collection, stereo calibration and rectification, and dataset development for visual SLAM under degraded imaging conditions. The dataset is [publicly available on Zenodo](https://doi.org/10.5281/zenodo.23347574).
- **Underwater localization and mapping** — Image preprocessing and enhancement, feature extraction and matching, SLAM development, and evaluation of localization and mapping performance. [ORB-SLAM2 adaptation](https://github.com/zhu-chengdong/slam2_18).
- **[Agricultural robotics · ongoing](https://github.com/zhu-chengdong/atarm-control)** — Robot system integration and debugging, SLAM, path planning, and robotic arm control for crop-health monitoring and agricultural applications.
- **[SolidWorks AI](https://github.com/zhu-chengdong/solidworks-ai)** — AI-assisted CAD modelling and engineering workflows using native SOLIDWORKS APIs. [Windows download](https://github.com/zhu-chengdong/solidworks-ai/releases/latest).
